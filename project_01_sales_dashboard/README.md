What I delivered:

- executive-ready dashboard logic and reporting structure

Tools used:

### Project 2: Real-Time Web Data Acquisition Pipeline

### Project 3: Predictive Customer Churn Engine

Business challenge:
A SaaS company was experiencing steady customer attrition and lacked a proactive system to identify at-risk accounts before they canceled. The result was a reactive retention strategy that created unnecessary revenue leakage.

What I delivered:
- customer churn prediction model using structured engagement signals
- feature engineering and risk scoring
- probability-based retention prioritization
- targeted outreach output for customer success teams

Tools used:
- Python
- NumPy
- Pandas
- scikit-learn
- Random Forest Classifier

Business impact:
- earlier detection of churn-prone customers
- stronger retention outreach prioritization
- reduced risk to recurring monthly subscription revenue

Repository:
- `project_03_churn_prediction_engine/`
