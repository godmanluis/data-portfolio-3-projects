# Business Data Portfolio

A 3-project data portfolio focused on business intelligence, automated data workflows, and predictive analytics for real business decisions.

## Overview

This repository demonstrates a practical progression from business reporting to operational automation to predictive intelligence:

1. Project 1: Executive Sales Performance Dashboard
2. Project 2: Real-Time Data Acquisition Pipeline
3. Project 3: Predictive Customer Churn Engine

Each project is designed to solve a real-world business problem and communicate measurable impact using data, automation, and stakeholder-friendly insights.

---

## Project Portfolio

### Project 1: Executive Sales Performance Dashboard

Business challenge:
A sales team needed a clear, trusted view of revenue performance, key account health, and regional gaps. Reporting was fragmented and inconsistent, slowing strategic decision-making.

What I delivered:
- Executive dashboard for activity, revenue, and performance trends
- KPI definitions and business logic
- Sales segmentation and pipeline review
- Data cleansing and transformation for reporting readiness

Tools used:
- Python
- SQL
- Excel
- Power BI

Business impact:
- Better visibility into gaps and wins
- Faster executive decisions
- Clearer performance accountability

Repository:
- `project_01_sales_dashboard/`

---

### Project 2: Real-Time Web Data Acquisition Pipeline

Business challenge:
The client needed up-to-date competitor and market information to monitor pricing, demand shifts, and external trends without manual effort.

What I delivered:
- Automated web scraping pipeline
- Structured data collection and transformation
- Clean data output for downstream analysis
- Repeatable ingestion workflow for ongoing monitoring

Tools used:
- Python
- Requests
- BeautifulSoup
- Pandas
- SQLite/PostgreSQL

Business impact:
- Reduced manual reporting effort
- Increased timeliness of market intelligence
- Enabled faster operational and pricing decisions

Repository:
- `project_02_real_time_data_pipeline/`

---

### Project 3: Predictive Customer Churn Engine

Business challenge:
A subscription-based SaaS company faced falling retention and lacked a proactive way to identify customers likely to cancel before revenue was lost.

What I delivered:
- Churn prediction model using machine learning
- Feature engineering and customer risk scoring
- Retention prioritization for customer success teams
- Actionable outreach file for high-risk accounts

Tools used:
- Python
- NumPy
- Pandas
- scikit-learn
- Random Forest Classifier

Business impact:
- Improved identification of at-risk users before cancellation
- Enabled proactive customer retention actions
- Reduced risk to recurring monthly revenue

Repository:
- `project_03_churn_prediction_engine/`
